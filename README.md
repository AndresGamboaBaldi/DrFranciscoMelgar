# My App

Proyecto base con **React + TypeScript + Tailwind CSS**, scaffoldeado con [Vite](https://vitejs.dev/).

## Stack

- ⚡ Vite
- ⚛️ React 19
- 🔷 TypeScript
- 🎨 Tailwind CSS v4

## Primeros pasos

```bash
npm install
npm run dev
```

## Scripts

| Script | Descripción |
|--------|-------------|
| `npm run dev` | Servidor de desarrollo |
| `npm run build` | Build de producción |
| `npm run preview` | Previsualizar el build |
| `npm run lint` | Linting con ESLint |
